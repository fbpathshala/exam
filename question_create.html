প্রশ্ন তৈরি

❏ Folder Management

Folder তৈরি, Rename বা Delete করার জন্য Category নির্বাচন করুন।

❏ Set Management

আগে Folder নির্বাচন করুন। তারপর সেই Folder-এর Set তৈরি/পরিবর্তন করুন।

❏ প্রশ্ন যোগ করুন

প্রশ্ন যোগ করার সময় Category → Folder → Set → বিষয় একই জায়গা থেকে নির্বাচন করুন।

❏ CSV / Excel থেকে প্রশ্ন যোগ

নিচের নির্বাচিত Category → Folder → Set অনুযায়ী সব প্রশ্ন সংরক্ষণ হবে।
