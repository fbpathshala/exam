১. Folder ও Set Management

প্রথমে Category ঠিক করুন। তারপর Folder → Set ক্রমে ম্যানেজ করুন।

Category→Folder→Set

📁 ফোল্ডার ম্যানেজমেন্ট

এই Category-এর Folder তৈরি, Rename বা Delete করুন।

📂 সেট ম্যানেজমেন্ট

আগে Folder নির্বাচন করুন, তারপর সেই Folder-এর Set ম্যানেজ করুন।

২. নতুন প্রশ্ন এড

প্রশ্নটি কোন Category → Folder → Set-এ যাবে, তা এখান থেকে নির্ধারণ করুন।

প্রশ্নের গন্তব্যCategory → Folder → Set

৩. CSV / Excel Upload

নির্বাচিত Category → Folder → Set-এ একসাথে অনেক প্রশ্ন Import করুন।
