১. ক্যাটাগরি, ফোল্ডার ও সেট ব্যবস্থাপনা

প্রথমে ক্যাটাগরি নির্বাচন করুন। এরপর ফোল্ডার তৈরি করে তার অধীনে প্রশ্ন সেট তৈরি ও পরিচালনা করুন।

ক্যাটাগরি→ফোল্ডার→প্রশ্ন সেট

📁 ফোল্ডার ব্যবস্থাপনা

নির্বাচিত ক্যাটাগরির ফোল্ডার তৈরি, নাম পরিবর্তন বা মুছে ফেলুন।

📂 প্রশ্ন সেট ব্যবস্থাপনা

প্রথমে ফোল্ডার নির্বাচন করুন। এরপর সেই ফোল্ডারের প্রশ্ন সেট পরিচালনা করুন।

২. নতুন প্রশ্ন এড

প্রশ্নটি কোন Category → Folder → Set-এ যাবে, তা এখান থেকে নির্ধারণ করুন।

প্রশ্নের গন্তব্যCategory → Folder → Set

৩. CSV / Excel Upload

নির্বাচিত Category → Folder → Set-এ একসাথে অনেক প্রশ্ন Import করুন।

Required: question, option_a, option_b, option_c, option_d, correct_answer. Optional: question_number, subject, explanation, category.

প্রশ্নের গন্তব্যCSV/Excel-এর সব প্রশ্ন এই নির্বাচিত Category → Folder → Set-এ যাবে।
